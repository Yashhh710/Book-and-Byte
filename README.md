# 📖 Book & Byte

**Your cozy digital notebook, inspired by the Minecraft world.**

Book & Byte is a Minecraft-inspired notes application that brings the feeling of writing in an in-game book to your browser.

### ✨ Features

- 📖 Interactive two-page book interface
- ✍️ Create, read, and edit notes
- 💾 Automatic saving on your device
- 📥 Download notes
- 📂 Document management
- 🎮 Minecraft-inspired pixel aesthetic
- 🌙 Immersive ambient background

### 🛠️ Built With

- HTML
- CSS
- JavaScript

### 🚀 Getting Started

1. Clone this repository.
2. Open `index.html` in your browser, or run it using the VS Code Live Server extension.
3. Start writing your notes!

### 🔒 Data & Privacy

Notes are saved locally on your device, depending on the application's implementation. Download and backup important notes regularly.
